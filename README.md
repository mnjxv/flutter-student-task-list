# Student Task List

A Flutter app where students add tasks with deadlines and check them off when done.

## Features

- Student profile card.
- Add tasks through a dialog with required-field validation (task name and deadline).
- Check off completed tasks (completed tasks are crossed out).
- Empty state when there are no tasks yet.

## Getting Started

```bash
flutter pub get
flutter run
```

## Running Tests

```bash
flutter test
```

## Project Structure

```
lib/
└── main.dart        # app, TaskPage, AddTaskDialog, Task
```
